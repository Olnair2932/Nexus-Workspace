# NEXUS Workspace

NEXUS Workspace é uma plataforma para criação e gerenciamento de páginas HTML para divulgação de produtos.

O projeto possui o NEXUS HTML STUDIO, responsável pela criação de anúncios, edição de páginas, imagens, vídeos e integração com inteligência artificial.

O NEXUS Acesso gerencia usuários, planos, limites de utilização e controle de acesso ao Studio.

Cada usuário possui um UID próprio, permitindo separar seus anúncios e controlar individualmente o uso dos recursos.

O projeto utiliza Node.js, Python, Firebase, Cloudinary e inteligência artificial, com publicação dos serviços no Render.
